# shm3041.github.io

코딩·AI·보안 학습 기록을 담은 GitHub Pages 블로그입니다.

- 배포 주소: https://shm3041.github.io
- 프레임워크: Jekyll (GitHub Pages 기본 빌드)
- 글은 `_posts/` 폴더에 `YYYY-MM-DD-슬러그.md` 형식으로 추가합니다.
- 다이어그램은 [Mermaid](https://mermaid.js.org)로 작성하며, 사이트에서 자동으로 렌더링됩니다.

## 로컬에서 실행하기

```bash
gem install bundler jekyll
bundle exec jekyll serve
```
