> **주제**: 게임 제작의 각 단계(**기획·아트·3D·코딩·오디오·QA·시연·홍보**)별 AI 도구를 비교하고, 상황에 맞는 선택을 제시합니다.

## 0. 핵심 결론 먼저

> **"모든 것을 잘하는 하나의 AI"는 없습니다.** 게임 제작은 단계마다 성격이 달라서, **단계별 강자를 조합**하고 **스택을 작게** 유지하는 것이 정답입니다. 2026년 가이드 대부분이 "파이프라인의 병목에 맞는 도구를 고르라"고 조언합니다.

## 1. 단계별 AI 도구 비교표

| 단계 | 추천 도구 | 잘하는 것 | 주의점 |
|------|-----------|-----------|--------|
| **기획/아이디어** | Ludo.ai, ChatGPT·Claude | 게임 아이디어·시스템 구상, 레퍼런스 조사 | 결국 방향 결정은 사람 |
| **2D 아트** | Scenario, Midjourney, Leonardo AI, Stable Diffusion | 콘셉트 아트, 캐릭터·배경, 스프라이트 | 상업 라이선스 확인 필수 |
| **3D 모델/에셋** | **Tripo**, **Meshy**, **Rodin**, Luma AI | 텍스트·이미지 → 3D 메시 생성 | 세밀한 리토폴·리깅은 사람 손 |
| **코딩** | **Cursor**, GitHub Copilot, Claude | C#·C++·GDScript 코드 작성 보조 | 생성 코드는 반드시 검토 |
| **애니메이션** | Cascadeur | 물리 기반 AI 보조 애니메이션 | 학습 곡선 존재 |
| **오디오(음악)** | **Suno** | 프롬프트로 배경음악 생성 | **라이선스 논쟁** — 상용 시 주의 |
| **오디오(음성/효과음)** | **ElevenLabs** | 음성 더빙·클로닝, 효과음 | 음성 권리·동의 확인 |
| **NPC 대화** | Inworld AI, Convai | 살아 있는 듯한 NPC 대화·행동 | 서버 비용·응답 지연 |
| **QA/버그 테스트** | modl.ai | AI 봇 자동 플레이로 버그 탐지 | 복잡한 논리 버그엔 한계 |
| **플레이테스트/시연** | modl.ai, Rosebud AI | 밸런스·난이도 자동 점검, 즉석 프로토타입 | 재미 판단은 사람 몫 |
| **홍보/마케팅** | Runway, Canva, ChatGPT·Claude | 트레일러 영상, 썸네일, 홍보 문구 | 브랜드 톤은 사람이 보정 |

> 📌 2026년 GDC 조사에서, AI를 쓰는 개발자 사이 **플레이테스트·밸런싱(약 47%)**이 가장 흔한 활용 사례로 꼽혔습니다. "콘텐츠 생성"만큼 **"테스트 자동화"**의 가치가 큽니다.

## 2. 3D 도구 자세히 보기 (Tripo · Meshy · Rodin)

3D 에셋 생성은 2026년에 특히 빠르게 발전한 분야입니다. 대표 3인방을 비교합니다.

| 도구 | 강점 | 메모 |
|------|------|------|
| **Tripo** | 빠른 생성 + **엔진 친화적 토폴로지** | GDC 2026에서 공개한 "Tripo P1.0"은 **깔끔한 쿼드 기반 토폴로지**의 모델을 생성해 엔진 임포트에 유리 |
| **Meshy** | 텍스트·이미지 → 3D의 **만능 올라운더** | "가장 빠른 올라운더"로 자주 언급 |
| **Rodin** | **텍스처 품질** | 일부 평가에서 "텍스처가 가장 좋다" (단일 의견) |

- **Tripo**: 쿼드 토폴로지 덕분에 **게임 엔진에서 바로 쓰기 좋은** 형태를 지향합니다. 애니메이션·리깅을 염두에 둔다면 유리합니다.
- **Meshy**: 입력 방식이 유연하고 속도가 빨라 **프로토타입 에셋을 빠르게** 뽑을 때 좋습니다.
- **Rodin**: 외형·질감이 중요한 장면용 에셋에 적합합니다.
- 보조로 **Luma AI**는 실제 사물을 **촬영해 3D로 복원**(포토그래메트리/캡처)하는 데 쓰입니다.

> ⚠️ AI가 만든 3D 메시는 **폴리곤이 지저분하거나 리깅이 안 된** 경우가 많습니다. 실제 게임에 넣기 전 **리토폴로지·UV·리깅** 단계에서 사람 손이 필요할 수 있습니다.

## 3. 오디오 — 음악은 라이선스를 조심

- **Suno**: 프롬프트로 배경음악을 생성합니다. 다만 **라이선스 문제가 논쟁 중**이라, 게임을 **판매할 계획이라면** 권리 관계가 명확한 음원을 쓰거나 사용 사실을 공개하는 편이 안전합니다.
- **ElevenLabs**: 음성 더빙·**보이스 클로닝**·다국어, 그리고 **효과음** 생성까지 지원합니다. 실제 사람 목소리를 복제할 때는 **동의·권리**를 반드시 확인하세요.

## 4. 코딩 — AI는 초안, 검토는 사람

- **Cursor**: 게임 프로그래머 사이 선호도가 높은 AI 코드 에디터. 프로젝트 맥락을 이해해 수정·리팩터링을 돕습니다.
- **GitHub Copilot**: 에디터 안 자동완성으로 빠르게 보조합니다.
- ⚠️ AI 코드는 **동작해도 비효율적이거나 버그가 숨어 있을 수 있어**, 반드시 사람이 읽고 검증해야 합니다.

## 5. 규모별 추천 조합

### 👤 1인 / 소규모 팀 (예산 제한)
- 2D: **Stable Diffusion**(무료·로컬) 또는 Scenario
- 3D: **Meshy** 또는 **Tripo** (무료 크레딧으로 시작)
- 코딩: **GitHub Copilot** 또는 Cursor
- 오디오: ElevenLabs(효과음) + (상용이면 음악 라이선스 주의)
- 홍보: **Canva + ChatGPT/Claude**
> 💡 무료·저가 도구로 시작하고, **병목 단계에만** 유료 도구를 추가하세요.

### 🏢 중대형 팀 / 상용 프로젝트
- 2D: **Scenario**(스타일 일관성) + Leonardo
- 3D: **Tripo**(엔진 친화) + **Rodin**(텍스처)
- 코딩: **Cursor**
- NPC: **Inworld AI**
- QA/플레이테스트: **modl.ai**
- 홍보: **Runway** + 전문 디자이너 보정

## 6. 공통 주의사항

1. **저작권·라이선스**: 생성물의 **상업적 사용 가능 여부**를 반드시 확인하세요. 특히 음악(Suno), 복제 음성(ElevenLabs)은 민감합니다.
2. **사람의 검토는 필수**: AI는 **초안 생성기**입니다. 코드·아트·3D·문구 모두 최종 책임은 사람에게 있습니다.
3. **가격은 수시로 바뀝니다**: 아래 추천은 2026년 기준이며, 요금제·기능은 자주 변합니다. 결정 전 **공식 페이지에서 최신 정보**를 확인하세요.
4. **스토어의 AI 표기 정책 확인**: 일부 플랫폼은 **AI 생성물 사용 여부 표기**를 요구합니다.
